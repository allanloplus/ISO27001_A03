# ISO 27001:2022 資訊保護生命週期｜動畫簡報

以 ISO/IEC 27001:2022 附錄 A 控制屬性「運作能力（Operational capabilities）＝ Information protection」為主軸，
沿資訊生命週期（政策制定 → 產生／收集 → 使用 → 儲存／存取 → 銷毀），
從 **ISMS 作業重點**、**稽核查核重點**、**常見缺失** 三個面向講解，並穿插 5 個管理實務案例與隨堂小測驗。
由 Q 版 Allan Lo 講師（台灣男聲 `zh-TW-YunJheNeural`）與助教阿拉蕾（台灣女聲 `zh-TW-HsiaoYuNeural`）以對話方式串場，搭配同步字幕。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 動畫簡報播放器（瀏覽器直接開啟，搭配 `audio/` 資料夾） |
| `video/ISO27001_資訊保護生命週期.mp4` | 已錄製好的完整教學影片（約 21 分鐘，1280×720） |

## 課程大綱（17 頁，約 19 分鐘）

1. 封面（講師與助教開場）
2. 資訊保護的運作流程（生命週期全貌動畫）
3. 政策制定（一）5.12 分類分級、5.13 標示
4. 政策制定（二）5.10 可接受使用、5.34 隱私及 PII 保護
5. 案例一｜精密製造業：「全部都是內部使用」的分級制度
6. 產生與收集 6.6 機密性或保密協議
7. 案例二｜電商平台：委外客服先上工、後簽約
8. 使用（一）8.1 端點裝置、8.7 防範惡意軟體、8.12 資料洩漏預防
9. 使用（二）8.11 資料遮蔽、8.33 測試資訊、8.34 稽核測試期間之保護
10. 案例三｜金融業系統商：十萬筆客戶資料進了測試區
11. 儲存與存取 5.14 資訊傳送、5.33 紀錄之保護
12. 案例四｜服務業人資：加密的薪資檔，密碼就在同一封信
13. 銷毀 8.10 資訊刪除
14. 案例五｜連鎖零售業：二手筆電還原出會員資料
15. 稽核技巧：一筆資料追到底
16. 阿拉蕾隨堂小測驗（3 題）
17. 課程總結（口訣：先分級、簽保密、用得穩、傳存好、刪乾淨）

案例皆為教學改編示例，非特定公司實際事件。講稿中每段的 `who` 欄位指定說話者（`allan` 或 `arale`）。

## 播放操作

- 封面按「開始上課」，講師與助教會逐格講解並自動翻頁。
- 封面的「選擇章節」或下方的「章節」按鈕（快捷鍵 `M`）可開啟章節選單，點選任一頁就從該頁開始講解。
- `空白鍵` 播放／暫停、`←` `→` 換頁、`C` 字幕、`F` 全螢幕、`Esc` 關閉章節選單。
- 暫停時換頁，該頁內容會完整顯示，可當一般投影片講課使用。
- 若瀏覽器無法播放音檔，會改用系統內建的 zh-TW 語音朗讀。

## 影片章節

MP4 已內嵌 17 個章節（每頁一個），VLC、PotPlayer、IINA、QuickTime 等播放器可直接從章節選單跳轉。上傳 YouTube 時，把 `video/youtube_chapters.txt` 的內容貼到影片說明欄，即會自動產生章節：

```
00:00 開場
01:04 生命週期全貌
02:26 政策制定
06:43 產生與收集
08:35 使用
13:32 儲存與存取
16:02 銷毀
17:54 稽核技巧
19:03 隨堂測驗
20:09 課程總結
```

## 修改講稿後重新產生

```bash
pip install edge-tts
python3 build.py                     # 只重新合成有變動的段落
node tools/record_video.cjs          # 需要 playwright 與 ffmpeg，重新錄製 MP4
```

旁白中的控制措施編號會自動轉成口語（例如「5.12」念成「五點一二」）。
