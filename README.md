# ISO 27001:2022 資訊保護生命週期｜動畫簡報

以 ISO/IEC 27001:2022 附錄 A 控制屬性「運作能力（Operational capabilities）＝ Information protection」為主軸，
沿資訊生命週期（政策制定 → 產生／收集 → 使用 → 儲存／存取 → 銷毀），
從 **ISMS 作業重點**、**稽核查核重點**、**常見缺失** 三個面向講解。
由 Q 版 Allan Lo 講師搭配台灣男聲（Azure `zh-TW-YunJheNeural`）旁白與同步字幕。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 動畫簡報播放器（瀏覽器直接開啟，搭配 `audio/` 資料夾） |
| `video/ISO27001_資訊保護生命週期.mp4` | 已錄製好的完整教學影片（約 12 分鐘，1280×720） |
| `content.json` | **課程內容與講稿**（投影片文字、旁白，修改這裡即可） |
| `template.html` | 版面、動畫與 Q 版講師 SVG |
| `build.py` | 產生旁白語音（含字幕時間軸），並組出 `index.html` |
| `tools/record_video.cjs` | 以 Playwright 自動播放並錄成 MP4 |

## 課程大綱（11 頁）

1. 封面
2. 資訊保護的運作流程（生命週期全貌動畫）
3. 政策制定（一）5.12 分類分級、5.13 標示
4. 政策制定（二）5.10 可接受使用、5.34 隱私及 PII 保護
5. 產生與收集 6.6 機密性或保密協議
6. 使用（一）8.1 端點裝置、8.7 防範惡意軟體、8.12 資料洩漏預防
7. 使用（二）8.11 資料遮蔽、8.33 測試資訊、8.34 稽核測試期間之保護
8. 儲存與存取 5.14 資訊傳送、5.33 紀錄之保護
9. 銷毀 8.10 資訊刪除
10. 稽核技巧：一筆資料追到底
11. 課程總結（口訣：先分級、簽保密、用得穩、傳存好、刪乾淨）

## 播放操作

- 封面按「開始上課」，講師會逐格講解並自動翻頁。
- `空白鍵` 播放／暫停、`←` `→` 換頁、`C` 字幕、`F` 全螢幕。
- 暫停時換頁，該頁內容會完整顯示，可當一般投影片講課使用。
- 若瀏覽器無法播放音檔，會改用系統內建的 zh-TW 語音朗讀。

## 修改講稿後重新產生

```bash
pip install edge-tts
python3 build.py                     # 只重新合成有變動的段落
node tools/record_video.cjs          # 需要 playwright 與 ffmpeg，重新錄製 MP4
```

旁白中的控制措施編號會自動轉成口語（例如「5.12」念成「五點一二」）。
